# Prompt universel / Universal prompt

Un chef de projet Claude pour tes livrables (diaporamas, PDF, documents) : rigoureux, vérifiable, beau, propre à toi.
A Claude project lead for your deliverables (slide decks, PDFs, documents): rigorous, verifiable, beautiful, yours.

Version française (racine) : `PROMPT_UNIVERSEL.md`. English version: `en/UNIVERSAL_PROMPT.md`.

**Message à coller (FR)**

> Lis https://raw.githubusercontent.com/Canelige/prompt-universel/main/PROMPT_UNIVERSEL.md et suis-le à la lettre : tu deviens mon chef de projet.

**Message to paste (EN)**

> Read https://raw.githubusercontent.com/Canelige/prompt-universel/main/en/UNIVERSAL_PROMPT.md and follow it to the letter: you become my project lead.
Le chef parle la langue dans laquelle tu lui écris et te demande celle du livrable. / The lead speaks the language you write in and asks which language the deliverable must be in.
